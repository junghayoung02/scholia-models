# Scholia

Scholia is an iPad app for reading, translating, and listening to PDF documents, including scanned books. Select a sentence, see the translation, hear it read aloud. Everything runs on your device.

This repository hosts the speech model files that the app downloads on first use, and the privacy policy.

## Support

Questions, bug reports, and feature requests: **scholia.app@gmail.com**

Please include your iPad model and iPadOS version when reporting a problem.

## Privacy policy

[privacy.md](privacy.md) (English and Korean)

## Model files

The `v1` release contains the Kokoro text-to-speech model (Apache 2.0). Checksums are in `checksums.txt`.

# Scholia

Scholia는 스캔한 책을 포함한 PDF 문서를 읽고, 번역하고, 들을 수 있는 아이패드 앱입니다. 문장을 선택하면 번역이 뜨고, 음성으로 들을 수 있습니다. 모든 기능이 기기 안에서 동작합니다.
